# Площадки подбора: что нужно, чтобы подключить их к порталу

Для руководителя отдела персонала «Рувер». Версия 1.0 от 30.10.2026.

Портал сейчас собирает резюме только с hh.ru. Этот документ — что нужно сделать на каждой следующей
площадке, чтобы агент собирал резюме и оттуда. Регистрацию компании делает сотрудник «Рувер»: площадки
подтверждают почту и телефон кодом, проверяют компанию по ИНН, а при регистрации компания принимает
оферту — это юридическое действие от её имени. Всё, что после регистрации, — подключение, ключи и
ежедневный сбор — делает разработка, как это было с hh.

Цены и условия ниже — по открытым источникам на 30.10.2026. Где официальных данных нет, так и написано:
это нужно уточнить у менеджера площадки до оплаты.

---

## Коротко

| Площадка | Поиск резюме через API | Регистрация компании | Доступ к базе резюме | Что делаем |
|---|---|---|---|---|
| **Работа России** (trudvsem.ru) | да, открытые данные | **не нужна** | бесплатно | подключает разработка сама |
| **SuperJob** | да, есть официальное API | нужна, кабинет работодателя | платный, тариф уточнить | регистрация, затем ключ приложения |
| **Авито Работа** | по сторонним данным — да, на старших тарифах | нужна, профиль компании на Авито | контакты платные | регистрация, уточнить тариф с API |
| **Зарплата.ру** | через hh — уточнить | не нужна отдельная: база принадлежит группе hh | через услуги hh | вопрос менеджеру hh |
| **Rabota.ru** | официального API для поиска не найдено | нужна | платные тарифы | только если менеджер подтвердит API |
| **Хабр Карьера** | нет: API отдаёт только отклики | нужна, компания на Хабре | в кабинете, платно | выгрузка по шаблону, уже работает |

**С чего начать:** Работа России (бесплатно, без регистрации), затем SuperJob (самое понятное API после hh)
и вопрос менеджеру hh про Зарплата.ру.

## 1. Работа России (trudvsem.ru)

Государственный портал занятости. Резюме и вакансии публикуются как открытые данные.

- **Регистрация компании:** не нужна.
- **Стоимость:** бесплатно.
- **API:** открытый, без ключей; в портале этот источник уже заведён и выключен до проверки.
- **Ограничения:** в открытых данных нет контактов соискателя; резюме чаще рабочих специальностей,
  инженеров и ИТ меньше, чем на hh.

**Что сделать вам:** ничего. Скажите «подключай Работу России» — разработка проверит адрес данных и
включит источник.

---

## 2. SuperJob (superjob.ru)

Вторая по величине площадка после hh. Есть официальное API: https://api.superjob.ru (документация
api.superjob.ru/doc/).

- **API:** поиск резюме — метод `GET /2.0/resumes/`, вход компании — OAuth 2.0, как на hh.
  Не чаще 120 запросов в минуту, до 500 резюме на один поиск.
- **Контакты:** в ответе есть признак «контакты куплены» — контакты открываются по тарифу или покупкой.
- **Стоимость:** публикация вакансий — порядка 2 000–12 000 ₽ за вакансию (сторонние обзоры). **Цену
  доступа к базе резюме и то, входит ли в него поиск через API, нужно уточнить у менеджера SuperJob.**

**Что сделать вам:**

1. Зарегистрировать компанию на superjob.ru в разделе «Работодателям»: ИНН, юридическое название,
   рабочая почта и телефон. Подтвердить почту и телефон кодом.
2. Спросить менеджера SuperJob:
   - сколько стоит доступ к базе резюме по нужным регионам (Краснодарский край, вся Россия для удалёнки);
   - открыт ли с ним поиск резюме через API (`/2.0/resumes/`) для собственной системы компании;
   - есть ли суточный лимит просмотров резюме.
3. Если условия подходят — оплатить доступ.
4. Зарегистрировать приложение: https://api.superjob.ru/register/ (войти как работодатель). Название —
   «Внутренняя система подбора компании Рувер», адрес возврата — `http://localhost:8000/api/oauth/superjob/callback`.
5. Прислать разработке: «приложение SuperJob зарегистрировано». Сами ключи (Secret key) в чат не
   присылайте — их вписывают в файл настроек на сервере, как ключи hh.

## 3. Авито Работа (avito.ru/rabota)

Сильна в рабочих и линейных профессиях: производство, склад, водители, продавцы.

- **API:** официальная документация — developers.avito.ru (раздел «Работа»). По данным интеграторов, в API
  есть поиск резюме, просмотр резюме и получение контактов. По тем же данным, API в категории «Работа»
  доступно только на максимальном тарифе и подключается с главного профиля компании.
- **Контакты:** открытие контакта платное (разово или пакетом).
- **Важно:** с 2025 года соискатель на Авито сам выбирает, каким работодателям открыть резюме, — часть
  резюме поиск по базе не покажет.
- **Стоимость:** **уточнить у менеджера Авито** — тариф с доступом к API и цену контакта.

**Что сделать вам:**

1. Завести на Авито профиль компании (юридическое лицо) — или проверить, нет ли его уже у компании.
2. Спросить менеджера Авито Работы:
   - какой тариф даёт API с поиском резюме и сколько он стоит;
   - сколько стоит открытие контакта;
   - есть ли суточные лимиты.
3. Если условия подходят — оплатить тариф и в настройках профиля получить **client_id и client_secret**
   для API (раздел для разработчиков в профиле Авито).
4. Сообщить разработке, что ключи получены. Сами ключи в чат не присылайте.

## 4. Зарплата.ру (zarplata.ru)

Площадка группы HeadHunter. По условиям hh, база резюме Зарплата.ру (zarplata.ru, rosrabota.ru,
rabota66.ru и других сайтов группы) доступна работодателю через программы hh.

- **Регистрация:** отдельная, скорее всего, не нужна — у компании уже есть учётная запись hh.
- **API:** отдельного публичного API не найдено. Возможно, резюме Зарплата.ру входят в поиск hh или
  подключаются отдельной услугой hh.

**Что сделать вам:** спросить вашего персонального менеджера hh:

- входят ли резюме базы Зарплата.ру в поиск через API hh по нашему тарифу;
- если нет — сколько стоит добавить доступ к базе Зарплата.ру и будет ли он виден через API.

Если да — разработке ничего подключать не нужно: резюме придут тем же сбором hh.

## 5. Rabota.ru

- **API:** официальной документации API для поиска резюме не найдено. Сторонние обзоры пишут об
  интеграции с ATS-системами, но это может быть только приём откликов.
- **Стоимость:** по сторонним обзорам — бесплатная вакансия в месяц, платные тарифы около 3 500 и
  9 000 ₽ за вакансию; доступ к базе резюме — на платных тарифах. **Проверить у менеджера.**

**Что сделать вам:** регистрироваться имеет смысл, только если менеджер Rabota.ru подтвердит, что есть
**API поиска резюме** для собственной системы компании. Спросите:

- есть ли API поиска по базе резюме и где его документация;
- сколько стоит доступ к базе и есть ли лимиты.

Без API собирать оттуда резюме автоматически нельзя: сбор со страниц сайта в обход API запрещён
правилами проекта и правилами самих площадок.

## 6. Хабр Карьера (career.habr.com)

Сильна в ИТ и электронике.

- **API:** бесплатное, но отдаёт только **отклики на вакансии компании** и профиль по логину. Поиска по
  базе резюме в API нет, выгрузки результатов поиска в файл тоже нет (проверено 28.10.2026).
- **Как работает сейчас:** рекрутер ищет людей в кабинете Хабр Карьеры и переносит их в шаблон
  `habr_шаблон.xlsx`; портал принимает файл сам (инструкция `docs/templates/habr_инструкция.md`).
- **Позже:** когда на Хабре будут вакансии «Рувер», разработка подключит автоматический приём откликов
  с полным резюме.

**Что сделать вам:** если компании ещё нет на Хабр Карьере — зарегистрировать её как работодателя.
Доступ к поиску по базе в кабинете — платный, цену уточнить у Хабра.

## Что прислать разработке после регистрации

| Площадка | Что сообщить | Что вписать на сервере (сами, не в чат) |
|---|---|---|
| SuperJob | «приложение зарегистрировано, доступ к базе оплачен» | Secret key, ID приложения |
| Авито Работа | «тариф с API подключён» | client_id, client_secret |
| Зарплата.ру | ответ менеджера hh | ничего |
| Rabota.ru | ответ менеджера про API | по документации, если API есть |
| Хабр Карьера | «вакансии опубликованы» | токен приложения Хабра — когда дойдём до откликов |

После этого разработка добавляет площадку в ежедневный сбор в 18:00, и резюме с неё появляются в «Базе»
вместе с hh — с тем же баллом по портретам должностей и без контактов до вашего решения.
