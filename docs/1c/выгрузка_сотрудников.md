# Выгрузка сотрудников из 1С:ERP для портала подбора

Для 1С-специалистов компании. Портал только читает файл, в 1С ничего не пишет.

**Куда класть.** В обменный каталог 1С (тот же, что для отчёта «Организационная структура»), имя файла —
`employees_<ГГГГММДД-ЧЧММСС>.json`. Достаточно раз в сутки, например в 06:00. Полный снимок, не дельта.

**Формат** (UTF-8):

```json
{
  "kind": "employees",
  "period": "2026-10-30",
  "employees": [
    {"id": "<идентификатор сотрудника в 1С>",
     "login": "<логин входа в 1С>",
     "full_name": "Иванов Иван Иванович",
     "department_id": "<id подразделения — тот же, что в отчёте «Организационная структура»>",
     "position": "Начальник отдела продаж",
     "active": true,
     "email": "<рабочая почта, если есть>"}
  ]
}
```

**Кого включать.** Всех работающих сотрудников. Уволенных — с `"active": false` или просто не включать.

**Что делает портал.** По должности и подразделению назначает роль: сотрудники отдела управления
персоналом — специалисты подбора; должности со словами «руководитель», «начальник», «директор» —
руководители подразделений; остальные — без доступа. Роль, исправленную вручную в портале, выгрузка не
меняет. Если из файла пропало больше 20 % сотрудников, файл не применяется — похоже на неполную выгрузку.

**Пароли не нужны и не передаются.** Пароль человек задаёт сам при первом входе по одноразовому коду из
отдела персонала.
