# API Хабр Карьеры: что он даёт

Конспект документации https://career.habr.com/info/api, прочитанной 2026-10-28.

## Главное

- API рассчитан на интеграцию с CRM кандидатов. Он отдаёт **отклики на наши вакансии**, размещённые на Хабр Карьере, и вместе с откликом полное резюме кандидата с контактами, кроме скрытых настройками приватности.
- **С базой резюме API не работает.** Документация говорит прямо: «API не предназначен для работы с базой резюме напрямую и для ведения переписки с кандидатами». Поиска специалистов в API нет.
- **Выгрузки результатов поиска в файл** в документации и справке Хабра нет. Значит, кандидатов из базы рекрутер переносит в шаблон `docs/templates/habr_шаблон.xlsx` вручную. Скачивать страницы программой нельзя (never.md).
- API бесплатный; платятся только публикации вакансий.

## Авторизация

- Приложение регистрируется на https://career.habr.com/profile/applications.
- Вход: `https://career.habr.com/integrations/oauth/authorize?client_id=…&redirect_uri=…&response_type=code`.
- Обмен кода: `POST https://career.habr.com/integrations/oauth/token` с параметрами `client_id, client_secret, redirect_uri, grant_type=authorization_code, code`. Код живёт 10 минут.
- `access_token` **бессрочный** (`scope: public`), refresh не нужен. Передаётся параметром `?access_token=…` в каждом запросе. Значит, токен попадает в адрес запроса: такие адреса нельзя писать в журналы.
- Базовый адрес `https://career.habr.com/api`, только JSON.

## Методы

| Метод | Что даёт |
|---|---|
| `GET /v1/integrations/users/me` | кто вошёл |
| `GET /v1/integrations/companies/my` | наша компания |
| `GET /v1/integrations/companies/{company_alias}/members` | сотрудники компании на Хабре |
| `GET /v1/integrations/billing_accounts` | счета компании и баланс |
| `GET /v1/integrations/vacancies`, `/vacancies/archived`, `/vacancies/:id` | наши вакансии |
| `GET /v1/integrations/vacancies/{vacancy_id}/responses?page=` | отклики на вакансию с данными кандидата |
| `GET /v1/integrations/users/{login}` | профиль пользователя по логину: город, переезд и удалёнка, опыт в месяцах, возраст, зарплата, заголовок, контакты, навыки, места работы с описанием, образование, курсы |

По документации непонятно, отдаёт ли `users/{login}` профиль любого человека или только откликнувшегося на нашу вакансию. Проверить на живом токене. Если отдаёт любого, это обогащение досье по нику Хабра, который рекрутер вписал в шаблон.

## Что это значит для нас

1. **Поиск по базе Хабра** — вручную: доступ к базе на 7 дней под конкретный подбор, перенос отобранных людей в шаблон, файл `habr_*.xlsx` в папку выгрузок.
2. **Отклики на наши вакансии на Хабре** можно забирать автоматически: отдельный коннектор, как для hh. Это задача после MVP или в фиче `workplace`, где появляются вакансии. Контакты в отклике приходят сразу, это зона кандидата, а не наблюдения (AD-3).
3. Перед коннектором — зарегистрировать приложение на Хабре и выяснить на живом токене поведение `users/{login}`.
