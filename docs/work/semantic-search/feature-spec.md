## Зачем — главная сессия

Отдел персонала (Котенко А., 20.11.2026): подбор по профилю ищет только точные ключевые слова. Широкий профиль даёт
«дичь», точный — 0 резюме; по инженеру-электронику на hh ~1400 подходящих, у портала 61. Рекрутер ищет руками на hh.
Причины в коде: запрос к hh — название + первые 6 ключей (`server/hr/hh.py:207`), балл — буквальные совпадения ключей
(`server/hr/scoring.py:164`, `:216`), за сбор — не больше 5 страниц по 50 на должность (`server/migrations/001_core.sql:87`).
Результат: портал находит похожих по смыслу и другой терминологии, балл остаётся у кода и объясним (AD-2).
Мерило — оценка Анастасии по выдаче для инженера-электроника до и после обновления.

## Решения — главная сессия

| Вопрос | Выбрано | Почему | Отвергнуто |
|---|---|---|---|
| Как мерить успех | мнение отдела: Анастасия сравнивает выдачу по инженеру-электронику до и после | человек, 2026-11-22 | эталонный набор резюме; рост числа найденных |
| Подход | синонимы ключей (расширяют запрос к hh и счёт ключей) + векторы bge-m3 (близость к профилю в балле, поиск в «Базе») | hh ищет по словам — векторы его выдачу не расширят; синонимы не найдут термин вне списка — нужны оба | только синонимы; только векторы |
| Кто даёт синонимы | локальная Qwen 8B на боевом сервере предлагает, рекрутер правит | модель уже стоит; разовая работа на профиль, на процессоре терпимо | словарь синонимов вручную |
| Модель векторов | bge-m3 на процессоре сервера портала (10.20.10.115), 1024 измерения — как `person_embedding` | видеокарта занята расшифровкой и Qwen, места нет (человек, 2026-11-22); bge-m3 работает без видеокарты, понимает русский | bge-m3 на видеокарте; Qwen как модель векторов |
| Нагрузка на Qwen | Qwen (`qwen2.5:7b-instruct`, Ollama на 10.20.10.6:11434, общая видеокарта) — только синонимы по кнопке рекрутера; общий предел вызовов в сутки настройкой; объяснения балла моделью на боевом выключены | ресурса видеокарты очень мало (человек, 2026-11-22); сейчас `llm_explain_per_run` = 500 вызовов за прогон (`server/migrations/001_core.sql:101`) — включение модели без предела её перегрузит | объяснения и черновики моделью |
| Проверка с настоящей Qwen | на разработке — заглушка модели; настоящую проверяет админ после обновления | Qwen доступна только в корпоративной сети, открывать её наружу ради разработки не нужно | туннель к Qwen с сервера разработки |
