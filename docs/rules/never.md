## Запреты проекта

- Не выполнять действие с человеком без подтверждения рекрутера: письмо, отказ, приглашение, открытие контакта — только через `action_queue` и кнопку.
- Не собирать данные со страниц в обход API и кабинетов: никакой ротации адресов, подмены отпечатка браузера, обхода капчи. Площадка показала проверку — задача останавливается.
- Не делать запросы к площадке чаще одного в секунду и больше `crawl_max_pages` страниц за прогон.
- Не отправлять контакты кандидатов в Telegram.
- Не передавать ФИО и контакты в запрос к языковой модели и в логи.
- Не пускать в скоринг профиль без `approved_by` и `approved_at`.
- Не принимать решения «отложить», «не наш» и закрытие вакансии с комментарием короче 200 знаков.
- Не менять `schema_recruiting.sql` ради MVP: дополнения — только миграциями в `server/migrations/`.
- Не править руками `.docx` и `.pdf`: правится исходник, файл пересобирается.
- Не извлекать из профилей в сети личное: только профессиональное; закрытые профили не трогать.
