# Заимствования

Скиллы `office-hours`, `qa`, `cso`, `careful`, `freeze`, `unfreeze` написаны заново по методам из
[gstack](https://github.com/garrytan/gstack) (Garry Tan, лицензия MIT): порядок вопросов, фазы аудита,
список опасных команд. Текст, проверки и скрипты — собственные, без кода gstack.

Часть правил `WORKFLOW.md` (выбор трека, дисциплина длинных обсуждений, правила текста спеки и плана)
и методика агентов `debugger`, `plan-reviewer`, `code-reviewer`, `test-writer` перенесены из прежнего
процесса проектов HiSi-Developing-Firmware и PTZ.

Сканер конфигурации агента — [AgentShield](https://github.com/affaan-m/agentshield) (`ecc-agentshield`,
лицензия MIT), используется как внешний инструмент.
