## WHAT — стек и структура

- Стек: Python 3.12, FastAPI, PostgreSQL 16 + pgvector + pg_trgm, psycopg 3, aiogram 3 (бот), faster-whisper (расшифровка голоса), docker compose. Интерфейс — статический HTML + JS без сборки.
- Документы-источники (корень репозитория):
  - `Агент_подбора_архитектура_v1.1.md` — что за система, источники, формула балла, решения заказчика
  - `ТЗ_для_инженеров_развёртывание.md` — стек, контур, переменные окружения, эндпойнты, приёмка из 48 пунктов (раздел 12)
  - `schema_recruiting.sql` — схема базы, разворачивается как есть; дополнения MVP — только миграциями в `server/migrations/`
  - `Рабочее_место_рекрутера.html` — прототип интерфейса, эталон экранов и текстов
  - `Мануал_рекрутера.md`, `Презентация_для_рекрутеров.pdf` — для заказчика; `.docx` и `.pdf` собираются скриптами `build_docx.py`, `build_deck_recruiters.py`, руками не правятся
- `server/` — код MVP (ветка `feature/mvp`): `hr/` — бизнес-логика и API, `migrations/`, `tests/`
- `docs/` — PRD, правила (`docs/rules/`), рабочие папки фич (`docs/work/<slug>/`)
- `.workflow/` — процесс разработки. Не редактировать: обновляется из Vadims workflow.

## WHY — назначение

Внутренняя система отдела персонала: каждое утро собирает резюме с площадок, сравнивает с профилями 83 должностей, следит за изменениями у людей в базе и показывает рекрутеру короткий список с объяснением. Действия с людьми агент только готовит, решает человек.

- сбор и конвейер — наполняют базу наблюдения без участия рекрутера
- рабочее место — экраны рекрутера и руководителя отдела персонала
- обмен с 1С — пользователи, заявки, оргструктура приходят файлами на чтение
- телеграм-бот — начальники отделов готовят черновики заявок

## HOW — команды

- Установка: `cd server && uv venv -p 3.12 .venv && uv pip install -r requirements.txt`
- База для разработки: `python -m hr.cli migrate` (нужен PostgreSQL 16 с pgvector и pg_trgm, адрес в `DATABASE_URL`)
- Запуск API: `uvicorn hr.main:app --reload` · фоновые задачи: `python -m hr.worker`
- Тесты: `cd server && pytest` · один тест: `pytest tests/test_scoring.py::test_name`
- Линтер: `ruff check server`
- Весь контур: `docker compose up -d`
